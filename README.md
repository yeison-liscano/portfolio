## Draft posts

Set `isDraft: true` in a post's frontmatter to preview it at
`/portfolio/blog/drafs/<post_slug>/`, where the slug is the content entry ID
(normally the filename without `.md` or `.mdx`). For example:
`/portfolio/blog/drafs/game-theory/`.

Drafts use the regular post layout and are accessible by direct URL. They stay
out of the blog listing, RSS feed, and sitemap, and include a `noindex` meta
tag. Set `isDraft: false` to publish at `/portfolio/blog/<post_slug>/` instead.
