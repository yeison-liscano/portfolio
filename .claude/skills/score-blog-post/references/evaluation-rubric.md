# Evaluation Rubric

## How to score

Score each of the 10 criteria 0, 1 or 2, for a total out of 20. A draft is ready
at 17 or more, with no zero on a gate.

- 2, strong: fully meets the "Strong" column.
- 1, partial: present but weak or uneven.
- 0, missing: absent, or works against the reader.
- Gates: criteria 1 (Title), 2 (Opening) and 10 (Payoff). A zero on any gate
  blocks publishing, whatever the total.

## The rubric

| #   | Criterion                | Strong (2 pts)                                                                                                | Quick test                                                                                    | Score |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ----- |
| 1   | Title (gate)             | Specific promise in plain words. Topic term in the first two words. Names the subject, holds back the answer. | Read only the first 11 characters: is the topic clear? Could a stranger say what they'll get? |       |
| 2   | Opening (gate)           | First paragraph states the problem, the stakes and the payoff. No warm-up.                                    | Stop after paragraph 1: did the reader get value and a reason to continue?                    |       |
| 3   | Headings                 | Each heading states a claim, not a label: "Tokens leak through redirect URIs", not "Background".              | Read only the headings: does the argument still hold?                                         |       |
| 4   | Scannability             | One idea per paragraph. Lists only for parallel items. No block over about 150 words. Bold used sparingly.    | Zoom out on the page: is there any wall of text?                                              |       |
| 5   | Sentences and tone       | Average about 15 words, none over 40. Objective, no hype. Jargon defined on first use.                        | Read it aloud: where do you run out of breath or wince?                                       |       |
| 6   | Narrative thread         | A real incident, investigation or decision drives the post. A question opens early and resolves later.        | Is there a point where the reader wants to know what happened next?                           |       |
| 7   | Value or surprise        | At least one surprising finding, or one thing the reader can use tomorrow.                                    | Name the line a reader would quote or the step they would copy.                               |       |
| 8   | Visuals                  | Every image carries information: diagram, code, annotated screenshot, chart. No stock photos.                 | Delete each image: does the reader lose information?                                          |       |
| 9   | Length                   | Every section earns its place. Length follows substance, not a word target.                                   | Cut a section: would anyone miss it?                                                          |       |
| 10  | Payoff and ending (gate) | Delivers what the title promised. Ends on one concrete takeaway, not a recap.                                 | Compare title and conclusion: did the post give at least what it promised?                    |       |

## Score bands and fix order

| Total                  | Verdict | Next move                                                      |
| ---------------------- | ------- | -------------------------------------------------------------- |
| 17–20, no gate at 0    | Publish | Polish the lowest row if time allows.                          |
| 12–16                  | Revise  | Fix rows scored 0 or 1, in the fix order below.                |
| 0–11, or any gate at 0 | Rework  | Rewrite title, opening and headings before touching sentences. |

### Fix in the order readers drop off:

1. Gates: Title, Opening, Payoff (1, 2, 10).
2. Structure: Headings, Scannability (3, 4).
3. Pull: Narrative, Value (6, 7).
4. Polish: Sentences, Visuals, Length (5, 8, 9).
